# Noir.os Terminal

Noir.os is a PowerShell-style terminal prototype with custom commands, theme switching, easter eggs and image output.

Open:

```text
index.html
```

## Features

- interactive terminal;
- PowerShell-inspired styling;
- command history with arrow up/down;
- built-in commands like `help`, `ls`, `dir`, `cd`, `cat`, `echo`, `date`, `whoami`, `neofetch`, `theme`;
- custom commands;
- easter eggs;
- image output from commands.

## Startup Text

Edit `startupMessage` in `commands.js`:

```js
const startupMessage = "Your startup text here";
```
